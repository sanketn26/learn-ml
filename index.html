📚 ML Fundamentals — 16 weeks (0–15)

Written for software developers and engineers who do not have a math background. Every new idea starts with an analogy you already know (SQL joins, code review, API contracts), a picture, then working code on CloudWave’s SaaS data.

How each week is taught: Think of it like… → Engineer mental model → live plots → a Watch out foot-gun → a Ship / don’t ship decision. Formulas appear only as “math, translated.”

📊 Sample Datasets Included

  • subscriptions.csv — 50,000 subscription records with lifecycle events
  • user_events.csv — 220,000 user activity telemetry records
  • feature_usage.csv — 160,000 feature engagement records
  • feedback.json — 10,000 customer feedback entries
  • product_catalog.csv — 300 product and feature definitions

All datasets are synthetically generated with realistic patterns to mirror production SaaS environments.

🎯 Getting Started

📁 Local Development

Clone the repository and run Jupyter locally: jupyter notebook notebooks/ to access the full interactive notebooks.

🌐 Online Viewing

View the HTML-rendered versions directly in your browser using the links above. These are automatically generated from the notebook files.

📝 Assignments

Each week includes assignments in the assignments/ folder. Work through these exercises to reinforce your understanding.

💾 Repository Structure

notebooks/ — Full interactive Jupyter notebooks for each week
docs/ — HTML renderings of notebooks for online viewing
data/ — Sample datasets for all exercises
assignments/ — Weekly assignments and reflection prompts
solutions/ — Reference solutions (when available)

Python 3.8+, Jupyter, NumPy, Pandas, Scikit-learn, and Matplotlib. See the README for full setup instructions.
