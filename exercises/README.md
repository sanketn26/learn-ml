# Exercises

ML weeks 16–20 are the job: `as_of` SQL, labels, ranking, `pipelines/`, on-call.

Each ML week has a folder:

```
exercises/ml/week-00/
  README.md
  starter.py
```

Run from the **repo root**:

```bash
python exercises/ml/week-00/starter.py
```

Lessons live on the site (`docs/ml/week-00.md`). Do not look for notebooks — there are none.

Framework courses (LangChain, LangGraph, CrewAI) keep the exercises in the lesson: copy a snippet into a `.py` file and run it with your API key in `.env`.
