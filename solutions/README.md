# Solutions — recovery path, not a spoiler dump

This folder is a **recovery path**. Use it when you have already tried the
exercise and are stuck — not as a first stop.

## The path

1. **Exercise** — `exercises/ml/week-XX/README.md` and `starter.py`.
2. **Hint 1** — high-level, in that week's `WRITEUP.md`. No code.
3. **Hint 2** — more specific (a function name or a shape). Still not the answer.
4. **Debugging clues** — what usually goes wrong on CloudWave data.
5. **Reference solution** — `solution.py`, plus the short snippets in the writeup.
6. **Why this decision** — two to four sentences on the engineering/ML choice.

!!! warning "Do not open `solution.py` until you are stuck after both hints"

    Opening the file early trains you to copy, not to debug. The writeup's
    collapsed `??? tip` / `??? warning` blocks exist so you can take one step
    at a time.

Run a reference solution from the **repo root**:

```bash
python solutions/ml/week-00/solution.py
```

Solutions exist for the foundational weeks, the hard-stats / production
weeks, and the capstone:

`week-00` … `week-05`, `week-07`, `week-08`, `week-15`, `week-16`, `week-17`,
and `capstone/`.

Other weeks follow the same recovery idea using the hints on the exercise
page. Do not put notebooks here.
